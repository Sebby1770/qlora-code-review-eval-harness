# Security Policy

The unreleased main branch is the currently supported development version.

Please report vulnerabilities privately through the repository's GitHub **Security** tab by
opening a private vulnerability report for `Sebby1770/qlora-code-review-eval-harness`.
Do not disclose secrets, exploitable prompt/data payloads, or vulnerable model artifacts in a
public issue. Include affected paths, reproduction steps, impact, and any suggested mitigation.
